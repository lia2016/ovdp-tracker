# ОВДП-трекер для Claude

Плагін для Claude, який веде облік ОВДП (військових облігацій), куплених коштами кредитних карток у межах пільгового періоду. Claude створює для вас Google Таблицю, рахує дату продажу облігацій перед погашенням кредиту, очікуваний і фактичний дохід, підказує найвигіднішу облігацію і ставить у Google Календар нагадування про продаж і про наступну покупку з кожної картки.

У плагіні **немає нічиїх особистих даних**. Є лише відомі нам умови банків (пільгові періоди), комісії брокерів і довідник облігацій. Під час першого запуску Claude розпитає вас про ваші картки, ліміти, брокерів і облігації, і лише потім побудує таблицю. Нічого не вигадує: чого не знаєте — залишить порожнім і підсвітить жовтим.

> Це інструмент обліку, а не фінансова порада.

## Що потрібно
- Акаунт Claude (Pro, Max або Team) з увімкненими **Code execution and file creation** і **Skills** (Налаштування → Capabilities).
- Підключені в Claude конектори **Google Drive** і **Google Sheets**; для нагадувань — **Google Calendar** (Налаштування → Connectors).

## Встановлення

### Варіант 1: з GitHub (оновлення приходитимуть самі)
1. Відкрийте Claude (вебверсію або застосунок Claude Desktop) → **Customize → Plugins**.
2. **Add marketplace** (або «Add plugin» → «Add from a repository»).
3. Введіть: `lia2016/ovdp-tracker` і підтвердіть.
4. У списку плагінів цього маркетплейсу знайдіть **ovdp-tracker** і натисніть **Install**.

Якщо пункти меню називаються трохи інакше — шукайте додавання маркетплейсу з GitHub-репозиторію.

### Варіант 2: завантажити скіл файлом
1. Завантажте `ovdp-tracker-skill.zip` з цього репозиторію (кнопка Download raw).
2. Claude → **Customize → Skills** → **+** → **Create skill** → **Upload a skill** → виберіть zip.
3. Увімкніть перемикач біля **ovdp-tracker**.

Оновлення в цьому варіанті вручну: завантажте новий zip, коли він з'явиться.

## Перший запуск
Напишіть Claude, наприклад:

> Налаштуй мені трекер ОВДП

Claude запитає:
1. Які кредитні картки використовуєте (банк, назва, кредитний ліміт) і їх умови. Для відомих карток покаже умови й попросить підтвердити; для Сенс Банку запитає число відкриття рахунку.
2. За скільки робочих днів до погашення продавати облігації.
3. Через яких брокерів купуєте (комісії відомих брокерів покаже).
4. Денний ліміт операцій по картці.
5. Які облігації відстежувати і їхні сьогоднішні ціни купівлі й продажу з застосунку.
6. Чи ставити нагадування в Календар (про продаж і про наступну покупку) і на котру годину.
7. Чи є вже зроблені покупки, які треба внести.

Потім покаже зведення, попросить підтвердження, створить таблицю «ОВДП — трекер покупок і розрахунок» у вашому Google Drive і дасть посилання.

## Щоденне використання
Просто пишіть Claude:
- «Купив 150 Алупка по 1016,27 на Smart через ICU, списано 152 745,38» — додасть покупку, порахує дату продажу й очікуваний дохід, поставить у Календар події «Продаж …» і «Покупка [картка] [ліміт]».
- «Сьогоднішні ціни: Алупка 1016,27 / 1003,75, …» — оновить ціни, скаже, яка облігація зараз найвигідніша.
- «Продав Алупку зі Smart за 153 900» — запише продаж і фактичний дохід.
- «Додай нову картку / нового брокера / нову облігацію» — розпитає умови й додасть.

## Структура репозиторію
```
.claude-plugin/marketplace.json        маркетплейс (для варіанту 1)
plugins/ovdp-tracker/                  сам плагін
  .claude-plugin/plugin.json
  skills/ovdp-tracker/SKILL.md         інструкції для Claude
  skills/ovdp-tracker/references/
    known-terms.md                     відомі умови банків, комісії, облігації
    sheet-spec.md                      як побудувати таблицю (усі формули)
ovdp-tracker-skill.zip                 той самий скіл одним файлом (для варіанту 2)
```

Знайшли, що умови банку чи комісія змінилися? Напишіть авторці — оновимо `known-terms.md`.
