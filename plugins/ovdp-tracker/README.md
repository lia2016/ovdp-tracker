# ovdp-tracker

Скіл для Claude, який веде Google Таблицю-трекер ОВДП (військових облігацій), куплених коштами кредитних карток у межах пільгового періоду. Під час першого запуску Claude розпитує про ваші картки, кредитні ліміти, брокерів і облігації, будує таблицю з формулами, а далі додає покупки, записує продажі, рахує дату продажу й очікуваний дохід і ставить нагадування в Google Календар. Потрібні конектори Google Drive і Google Sheets (Calendar — за бажанням).

Встановлення й приклади — у README в корені репозиторію.
